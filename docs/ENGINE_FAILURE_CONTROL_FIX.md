# 场景一低速复飞控制修复

## 适用工况

初始高度400 ft，初始空速参数140 ft/s，左发失效高度250 ft，复飞高度150 ft，目标高度400 ft，无风。

`STEP_TIME`保持2.0秒。飞机模型、场景参数和配平算法保持原配置。

## 修改内容

1. 复飞后的首个控制区间即开始向爬升配平过渡，过渡时间仍为6秒。
2. 取消固定0.12油门下限，使单发下降控制能够保持约0.092的实际配平油门。
3. 右发油门变化限幅调整为每秒0.08，方向舵每秒0.05，副翼每秒0.03；升降舵仍为每秒0.006。以上为模型控制指令变化率。
4. 降低滚转、偏航反馈增益；空速不足时降低俯仰修正目标，协调推力、姿态与空速。
5. 触地、空速或姿态越界、关键状态非有限值时返回`done=true`和具体终止事件。重复调用返回已终止结果，不再推进仿真。
6. 自动评估增加零高度及非有限值检查。

控制器位于`src/multiflight/simulation/engine_failure_control.py`，终止检查位于`src/multiflight/simulation/flight_safety.py`。
