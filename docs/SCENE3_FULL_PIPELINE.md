# 场景三完整仿真流程验证

## 已接入流程

前端或API选择 `ground_direction` → 自动选取提示词版本 → 编译场景约束和策略并计算哈希 → Dify Agent调用reset/step → 真实MATLAB连续仿真 → 后端自动评估 → 保存报告。

场景三现已在统一场景注册中启用，提示词基线版本为 `0.1.0`。版本通过现有PromptStore管理；加入新场景时保留场景一已存在的版本及回归记录。场景三提示词由 `ground_contract.md` 和 `scenes/ground_direction.md` 等文件组成，日志保存实际编译全文和哈希。

本轮按预算只执行一次真实Agent会话，不运行基线/候选批量优化。优化入口已使用场景三专用候选规则，但候选运行、自动发布和离线小模型尚未验证。

## Agent与底层分工

使用Dify现有reset_simulation和step_simulation工具，字段不变，不需要重新配置Dify工具。

1. Agent调用reset，返回READY、静止状态、75度右转目标和5 kn目标速度。
2. Agent下达三个舵面0、左右油门0.4。底层PI速度控制加速到5 kn，保存完整ModelOperatingPoint后返回TURN_READY。
3. Agent读取真实状态，再下达三个舵面0、左油门0.4、右油门0，选择内侧零推力方案。MATLAB从同一保存状态继续，前轮按场景设定的30度/秒向75度偏转，外侧油门闭环控速。达到177度且运动方向反转后停止。
4. 后端验证阶段顺序、控制格式、加速门槛、阶段状态连续性、实际75度轮角、接地和完成条件。

左右油门字段在此地面场景表示控制上限与侧别策略，底层实际油门序列另行记录。前轮角由固定工况给定，不使用方向舵字段代传。step推进到阶段终点，而非场景一固定2秒。Agent负责阶段动作选择，20 Hz低层控制器负责连续调节，不是Agent每50毫秒直接驾驶。

完整轨迹保留在实验目录，工具只向Agent返回状态和摘要以减少上下文费用。后续每一阶段使用独立checkpoint文件，便于审计。

## 本轮真实结果

实验ID：`run-766927194d3c`。实际执行一次reset、两次step；Agent先选择对称加速，再选择内侧右油门0。提示词版本 `0.1.0`，实际全文哈希：`47448d6641351515401a6a720f9a0856ef1f4a806de68598cf79491fe3ae5414`。

3.85秒达到5.0527 kn；第二段从保存状态继续，第一条日志时间3.850009613秒，位置变化约0.025毫米，与约10微秒的求解器推进相符。7.45秒结束，第二段航向变化177.675度，实际前轮最大75度，最低转弯速度3.613 kn，末速度4.411 kn，最大滚转约1.99度，三轮保持接地。

首次评估对不同时间点使用统一的过严数值阈值，报告STATE_DISCONTINUITY。修正为“日志间隔不超过1毫秒，位置变化不超过速度乘间隔及10微米数值余量，速度变化也受间隔约束”后，对同一批原始数据重新评估，八项门槛均通过。未重新调用Agent或重跑模型。初始失败报告保存在 `evaluation.initial.json`，最终报告为 `evaluation.json`，包含重新评估原因。

Agent自然语言总结存在个别解释错误，例如把零油门描述为发动机关闭、混淆固定差值参数与实际左右油门差；原始回答保留供审计。结果以工具原始数据和确定性评估为准，不能直接把Agent总结作为技术验收结论。

## 调用和交付

启动/重启后端后，在Swagger或前端调用统一接口：

```json
POST /api/runs
{"scene_id":"ground_direction"}
```

不需要用户输入提示词；省略prompt_version时自动选择 `0.1.0`。通过 `GET /api/runs/{id}` 查询状态，通过 `GET /api/runs/{id}/report` 获取报告。版本和提示词分别使用现有 `/api/prompts/ground_direction/versions` 与 `/api/prompts/ground_direction/compiled`。

完整材料位于 `data/runs/run-766927194d3c/`：编译提示词、Dify真实工具调用记录、两段输入和模型轨迹、checkpoint、records.json、初始及最终评估报告。该次调用也能通过统一运行列表查到。

此版本为固定75度右转功能流程，参数准备接口尚未扩展到地面工况，左转与正副驾驶独立通道尚未验证。速度未全程恒定5 kn，零推力不是真实慢车标定。完整流程通过不等同原始试验点2-1全部验收。
