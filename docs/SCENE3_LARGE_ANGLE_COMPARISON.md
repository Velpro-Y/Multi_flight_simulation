# 场景三大角度掉头与差动油门对照

2026年11月10日，使用同一地面模型，分别在20°、40°、60°、75°目标前轮角下比较双发对称油门与内侧零油门、外侧PI速度控制。各组均从静止开始，对称加速到5 kn后转弯；方向为右转，结束阈值为航向变化达到177°并且沿初始方向的速度为负。未调用Agent，没有保存或覆盖SLX。

## 方法和边界

20°、40°、60°两组均采用15°/s转向变化限制。最大目标角保持至航向变化150°，随后按剩余航向误差回收转角。全过程检查有限数值、滚转小于10°和三轮接地；滚转达到10°会触发停止，更大角度不再继续。

首轮75°使用15°/s，两组完成掉头但最大指令角仅66.75°和65.25°，没有覆盖75°，因此该角度试验判为未通过，原始结果保留。随后仅补做一对30°/s的75°工况，并在前轮 `WheelKinematics/WheelCos` 输入处直接记录实际轮角，两组均实测达到75°。30°/s是本次控制器设定，不是执行机构性能标定值；各角度间不能把结果差异全部归因于转角。

## 对照结果

表内每格顺序为“对称油门 / 内侧零油门”。时间包含从静止加速的3.85秒。轨迹横向占用由完整内部时序的Ye最大值减最小值计算，为重心轨迹范围，不是机体或机轮扫掠宽度。

| 目标角及速率 | 总时间 s | 横向占用 m | 最大滚转 ° | 最低转弯速度 kn |
| --- | --- | --- | --- | --- |
| 20°，15°/s | 17.65 / 17.50 | 19.288 / 19.126 | 0.829 / 0.785 | 5.009 / 4.914 |
| 40°，15°/s | 9.55 / 9.55 | 8.528 / 8.441 | 1.516 / 1.532 | 5.053 / 5.053 |
| 60°，15°/s | 8.70 / 8.60 | 6.465 / 6.306 | 1.961 / 2.211 | 4.882 / 5.003 |
| 75°，30°/s，实测达到75° | 7.90 / 7.45 | 4.858 / 3.876 | 1.870 / 1.972 | 3.152 / 3.588 |

四对最终对照均满足本次掉头、姿态及接地判据。75°对照的航向变化为177.624°/177.250°；末速度为3.758/4.406 kn。差动组外侧平均推力936.44 N，内侧0 N，发动机平均偏航力矩3277.54 N·m。

75°对照中，差动方案总耗时减少约5.7%，转弯阶段耗时从4.05秒减少到3.60秒，横向轨迹占用减少约20.2%，最低速度提高约0.44 kn。相较小角度，该工况下差动方案的辅助作用更明显。但两组速度不同且均低于5 kn目标，不能将全部变化归因于差动力矩，也不能宣称完成全程5 kn恒速验证。

内侧零油门在本模型中对应零推力，并非真实发动机慢车标定。结论仅针对当前模型及右转；不覆盖左转、正副驾驶独立操纵、执行机构速率标定或真实飞机最大能力验证。默认前端Demo API的转向范围仍为±10°；大角度目前通过独立验证脚本运行。
