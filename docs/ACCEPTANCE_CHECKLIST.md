# v0.2.0 验收与合并检查表

## 1. 通用提交检查

- [ ] 功能在独立 feature 分支完成，没有直接提交到 `main`。
- [ ] 变更范围符合 [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md) 的目录边界。
- [ ] 没有提交 `.env`、API Key、数据库、日志、临时 MAT、`slprj` 或 `*.slxc`。
- [ ] 没有引用 `E:\6DOF_Airframe` 或开发者本机绝对路径。
- [ ] README 或对应交付文档已同步更新。
- [ ] 合并说明中包含测试命令、结果和已知限制。

## 2. 后端与算法验收

- [ ] `GET /api/scenarios/{scene_id}/parameters` 返回字段、单位、范围、默认值和能力状态。
- [ ] 场景一高度关系不合法时返回 `422`，且包含具体字段错误。
- [ ] 当前模型不支持的非零风场不能被静默忽略。
- [ ] `POST /api/simulations/prepare` 能返回可追溯的 `preparation_id`。
- [ ] 配平不收敛时不会启动 Dify 或 Simulink 正式运行。
- [ ] `/api/runs` 只能使用同场景且未过期的配平结果。
- [ ] 运行结果记录规范化参数、配平结果、模型版本、提示词版本及哈希。
- [ ] 前端请求中不需要提示词文本。
- [ ] 场景二继续返回不可运行状态。
- [ ] 场景三评价器能够识别字段缺失、越界、方向错误和任务是否完成。
- [ ] `pytest -q` 全部通过。

## 3. Simulink 模型验收

- [ ] 场景三模型、固定工况验证脚本、基准结果和模型说明均已提交。
- [ ] 场景三模型输入输出信号符合 [SCENE3_MODEL_CONTRACT.md](SCENE3_MODEL_CONTRACT.md)。
- [ ] 场景三具备地面接触、轮胎侧向力和前轮转向或等效转向能力。
- [ ] 转向控制方向经过正负输入测试。
- [ ] 横向偏差和航向误差的正方向、单位已经说明。
- [ ] 模型负责人未承担场景一配平、reset/step 系统封装或后端接口开发。
- [ ] 本版没有实现差动刹车或场景二刹车模块。
- [ ] 在不打开 `E:\6DOF_Airframe` 的条件下可以独立运行。

场景一动态配平和场景三 reset/step 适配属于后端与算法负责人的集成验收，不属于模型负责人交付验收。

## 4. 前端验收

- [ ] 场景列表来自 `/api/scenarios`，没有硬编码可用状态。
- [ ] 参数表单来自场景参数 Schema。
- [ ] 单位、范围、默认值和禁用原因正确展示。
- [ ] 表单提交前执行基础校验，但最终以后端校验为准。
- [ ] 配平进行中、成功、失败均有明确状态。
- [ ] 使用后端返回的 `preparation_id` 启动实验。
- [ ] 正确轮询并处理 `queued`、`running`、`succeeded`、`completed_with_failures`、`failed`。
- [ ] 展示实验阶段、进度、评价结果和后端错误消息。
- [ ] 不显示或存储 Dify API Key，不提供提示词输入框。
- [ ] 场景二显示“刹车模块暂缓”，场景三未验收前显示“开发中”。

## 5. 集成演示用例

### 用例 A：v0.1.0 回归

- [ ] 使用默认参数完成固定单发失效复飞。
- [ ] 阶段顺序为 `TWIN_DESCENT → ENGINE_OUT_DESCENT → GO_AROUND → SUCCESS`。
- [ ] 原有 9 项自动化测试继续通过，新增测试不得破坏基线。

### 用例 B：场景一参数化成功

- [ ] 使用一组非默认且合法的参数完成配平。
- [ ] 实际事件高度和目标高度与请求参数一致。
- [ ] 运行结果能够追溯本次参数与配平结果。

### 用例 C：场景一参数失败

- [ ] 设置“复飞高度高于失效高度”，后端在仿真前拒绝。
- [ ] 设置超出验证范围的空速，后端返回字段级错误。
- [ ] 设置无法配平的工况，后端返回 `TRIM_NOT_CONVERGED`。

### 用例 D：场景三默认工况

- [ ] 默认工况完成 reset 和连续 step。
- [ ] 返回横向偏差、航向误差、地速和偏航角速度。
- [ ] 任务成功或失败由标准事件和评价报告明确说明。

### 用例 E：暂未实现能力

- [ ] 场景二无法启动且原因明确。
- [ ] 场景三差动刹车输入不会被描述为已生效。
- [ ] 风场未接入时，非零风速请求不会被静默接受。
