## 2. 关键验证结果

| 验证 | 结果与证据 |
| --- | --- |
| 场景一参数测试 | 15 组完成测试：14 组复飞组合中 13 组成功，1 组 135 ft/s 配平失败，另 1 组 60 秒时限对照。不是 15 次 Dify 验证 |
| 场景一低速完整 Dify | `run-edd992a67402`，46 步，92 s，最终 409.36 ft，最低 113.76 ft，7 项检查通过 |
| 场景一较高初始状态完整 Dify | `run-b9ad78d61d2e`，47 步，94 s，最终 508.29 ft，7 项检查通过 |
| 场景三 0.2.0 全新 Dify | `run-a4a1902d74ef`，17 次调用、0 复用，8.08 s，航向 177.447°，实际轮角 75°，7 项检查通过 |
| 75°差动油门配对 | 30°/s，耗时 7.90→7.45 s，重心横向占用 4.858→3.876 m，分别减少约 5.7%、20.2%，无 Dify 调用 |
| 刹车模型直接测试 | 11 个工况，12 项检查通过，包含单侧刹车、自动互斥、接地触发及三档速度限角 |
| 刹车连续协议 | `ground-brake-protocol-2e09b65e5d`，11 步、5.5 s，8 项检查通过，0 次 Dify 调用 |
| 0.3.0 常规 Dify | `run-b8ae51974dc2`，17 次调用、0 复用，8.12 s，9 项检查通过，本轮未使用刹车 |
| 0.3.0 刹车专项 Dify | `run-d38f47576572`，18 次调用、0 复用，8.91 s，航向 177.32°，实际轮角 75°，9 项检查通过，手动及自动刹车均使用 |
| 2026-11-20 代码测试 | `python -m pytest tests -q`，41 项通过，未重新调用 Dify 或运行真实模型 |

差动油门结论仅针对当前模型与有限右转工况。各对内部转角及速率一致，但速度过程不同；20°/40°/60°采用 15°/s，75°采用 30°/s，不能把跨组差异单独归因于转角。内侧零油门是模型零推力，横向占用为重心轨迹范围，均不是实机慢车或机体扫掠宽度。

刹车专项 Dify 运行的左右油门相同，不能用其结果证明差动油门收益。
